Cómo reprogramar tu llavero NFC

Usa un teléfono compatible con escritura NFC para cambiar el enlace de tu llavero. Ten a la mano la dirección completa que quieres grabar, por ejemplo, la de tu menú, perfil o página de contacto.

NFC Tools para Android NFC Tools para iPhone
  1. Abre NFC Tools. Si usas Android, activa el NFC en los ajustes del teléfono.
  2. Entra a Escribir → Añadir un registro → URL/URI. Pega tu enlace completo, incluido https://, y confirma el registro.
  3. Pulsa Escribir y acerca el llavero al teléfono. Mantenlo quieto hasta que la app confirme la escritura.
  4. Retira el llavero y vuelve a acercarlo. Comprueba que abra el enlace nuevo.

Al grabar se reemplaza el contenido anterior del chip. Guarda el enlace anterior si quieres conservarlo. Para poder cambiarlo otra vez, deja el chip en modo regrabable.
