Aviso de privacidad — solicitudes de propuesta

Lapazimpresion3d utiliza el nombre, número de WhatsApp, nombre de proyecto y comentarios que proporcionas voluntariamente para revisar tu solicitud, contactarte y elaborar una propuesta.

Las respuestas del cuestionario, la recomendación, la fecha y el folio se almacenan junto a la solicitud en Cloudflare D1. El acceso administrativo está restringido. No se utilizan para publicar tus datos ni para enviar publicidad por defecto.

Compartir los datos es voluntario, pero necesitamos nombre y contacto para atender una propuesta. Puedes solicitar consulta, corrección o eliminación de tus datos contactando a Lapazimpresion3d por los canales publicados en la página principal, indicando tu folio.

La infraestructura técnica de Cloudflare puede procesar datos para prestar el servicio. El aviso puede actualizarse al incorporar nuevas funciones de recepción, notificación o conservación de datos.

Antes de usar este formulario con clientes reales: el responsable del sitio debe completar el aviso integral conforme a la normativa aplicable, incluyendo identidad y domicilio del responsable, medios efectivos para derechos ARCO, transferencias y plazos de conservación.
