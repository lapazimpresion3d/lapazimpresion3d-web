# Tablero de trabajo
Consulta administrativa de hasta 500 proyectos activos, sin historial, mensajes, tokens ni archivos. Fecha de referencia de La Paz. Vencida = estimada anterior a hoy, próxima = hoy a siete días inclusive; no se marca si entrega registrada. Revisión pendiente o requiere cambios según registro de entrega. Materiales pendientes significa que no existe confirmación explícita, no que no se hayan recibido. No modifica estados. Permite abrir un proyecto fuera del listado reciente de 100. Migraciones 0007/0008 se detectan y la vista informa si faltan. Pruebas de navegador y D1 pendientes.
