# Entrega, publicación y seguimiento
Migración 0007: proyecto_entregas y proyecto_cambios. Cada proyecto existente puede registrar modalidad física, web o combinada, una revisión numerada y descripción. Para web se requiere enlace HTTPS sin consulta, fragmento o credenciales, alojado previamente. No se aloja ni protege automáticamente la vista previa; no introducir URLs secretas (incluidos tokens en rutas). En el portal privado, el cliente aprueba la versión o pide cambios; el administrador también puede registrar una decisión comunicada externamente con confirmación explícita. Nueva revisión incrementa versión y restablece decisión; las escrituras verifican versión, estado y aprobación. No hay historial de versiones de revisión en esta etapa, solo la actual.
Tras aprobación, registrar entrega efectiva y, para web, publicación, URL final, dominio propio/subdominio. Fecha de garantía de desarrollo = entrega +60 días, según condición comercial publicada; no implica garantía física. No cambia automáticamente el estado general ni activa mensualidad: ambas acciones siguen en sus controles existentes. Registro interno de modificaciones posteriores sin cobro automático ni cambio de precio. Portal cliente muestra revisión/entrega, no modificaciones internas. No modifica DNS, repositorios de clientes, Cloudflare ni despliega sitios. Acceso de cliente sigue sujeto al enlace vigente y reglas previas; finalizado permite lectura con acceso vigente pero no emitir nuevo enlace por ahora.
Aplicar 0007 tras respaldo, verificar 0004–0006 y probar en D1 local. Ninguna migración remota aplicada. El módulo se consulta separadamente para preservar solicitudes/materiales previos.
