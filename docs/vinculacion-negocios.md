# Vinculación administrativa de negocios
Migración 0013. Un registro vigente por servicio y por pareja plataforma/identificador externo. Identificadores canónicos ASCII en minúsculas (plataforma 1–80, negocio 1–128); confirmar compatibilidad con el identificador estable del repositorio de demos antes de registrar. La vinculación es administrativa, no es autenticación ni concede acceso. Revocación con motivo y confirmación, historial conservado; no se reactiva un registro revocado, se crea otro. No cambiar contrato, mensualidad, sitio ni DNS. API admin GET/POST /api/admin/servicios/:propuesta_id/vinculos y PATCH /:id. Autorización y origen existentes, UUID idempotente, unicidad D1 y borrado bajo candado existente. No asignar IDs de demos a clientes reales. Pendiente definir identidad autenticada, transporte Service Binding o alternativa, validación de entorno, autorización por operación, revocación efectiva y pruebas de aislamiento. No hay API externa ni credenciales nuevas. El registro vigente no equivale a conexión verificada. Vista historial hasta 100.
