# Auditoría reproducible
Ejecutar desde raíz con Python 3: python scripts/auditar-migraciones.py. Usa SQLite en memoria, aplica migraciones en orden, revisa integridad y claves foráneas tras cada archivo, prepara SQL literal del Worker mediante EXPLAIN sin ejecutar mutaciones. No usa red, secretos, D1 remoto ni R2. SQL compuesto dinámicamente y consultas de otros módulos no se cubren todavía. Workflow manual Auditoría local SQLite, sin despliegue; resultados en Actions. El inventario de producción confirmado por usuario incluye las cuatro tablas de 0027–0029, no certifica todas las columnas. No ejecutar migraciones remotas por esta auditoría.
