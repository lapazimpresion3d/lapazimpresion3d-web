# Recopilación flexible y seguimiento simplificado
Confirmación administrativa explícita desde Seguimiento de Mi proyecto, con origen y observación visible al cliente. Completa únicamente la etapa inicial e inicia la siguiente si no había etapa actual o estaba en recopilación; conserva una etapa posterior. No altera revisiones individuales. La recopilación confirmada no se desmarca ni se vuelve a confirmar desde este formulario. El cliente conserva acceso a materiales, que se muestran plegados tras confirmación. No exige archivos. Adjuntar referencias externas como materiales administrativos queda pendiente; no confundir fotografías de avances con materiales. Formato simplificado de cuatro etapas para las tres modalidades, seleccionable antes de primera publicación. Historias antiguas siguen detalladas. Sin migración adicional: usa 0008. 0009 sigue necesaria para fotografías.
