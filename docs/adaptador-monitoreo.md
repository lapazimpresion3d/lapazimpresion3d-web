# Adaptador de monitoreo — preparado, no activo
Worker RPC independiente src/adaptador-monitoreo.mjs, EgresoMonitoreo.comprobar(sitio). Requiere ADAPTADOR_MONITOREO_HABILITADO=si, EGRESO_SITIOS_AUTORIZADOS lista JSON exacta y TRANSPORTE_MONITOREO binding privado. El orquestador existente requiere MONITOREO_EGRESO al entrypoint, lista independiente y flag propio. Sin transporte no hace fetch. No hay rutas públicas.
scripts/transporte-monitoreo.mjs es núcleo de transporte Node, no servidor. Verifica URL HTTPS exacta de lista independiente, DNS con límite 3s, rechaza IPv6 y respuestas mixtas o IP no públicas (conservador), conexión HTTPS a IP validada con SNI/Host del dominio y validación de certificado, sin redirecciones, sin credenciales, sin lectura de cuerpo, límite total 10s. No permite URL arbitraria ni usa proxy. DNS fallido/bloqueado y errores no clasificados devuelven ok:false, sin registrar caída. Errores de conexión/TLS observados devuelven código null; HTTP conserva código sin seguir redirección. Tiempo incluye DNS y conexión. No mide uptime ni funciones internas.
