# Plataforma autoadministrable: alcance objetivo
La mensualidad se comunica como acceso continuado a la plataforma, alojamiento, seguridad, respaldo según módulo, soporte y mejoras generales compatibles. Las operaciones realizadas por el cliente en el panel habilitado no consumen minutos ni generan cargo por modificación. Se mantienen los precios; no se ofrecen bolsas de minutos. No se prometen desarrollos exclusivos o funciones nuevas cada mes.

## Desarrollo y aceptación
P1: edición de identidad, contacto, horarios, catálogo, productos, categorías, imágenes, disponibilidad, avisos y promociones; estadísticas agregadas de visitas, consultas, WhatsApp y accesos QR etiquetados, sujetas a consentimiento. P2: añade gestión e historial de pedidos/citas, estados, filtros, actividad y exportación. P3: añade caja, ventas, inventario básico, cortes y reportes. P4: añade costos, proveedores, inventario avanzado, permisos, automatizaciones y comparativos. Cada módulo debe probarse por giro, con aislamiento entre negocios, validación de entradas, acceso autenticado, límites de uso, respaldo y restauración. No se debe presentar como operativo antes de verificarlo. El repositorio de demos no se modificó. Las mejoras comerciales se aplican a nuevas propuestas; no cambian contratos aceptados automáticamente.
