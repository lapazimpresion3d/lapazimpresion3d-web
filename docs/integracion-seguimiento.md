# Integración Mi proyecto
El resumen consulta la revisión vigente mediante las APIs existentes; no replica decisiones ni cambia etapas automáticamente. La respuesta del cliente actualiza el resumen inmediatamente. El panel enlaza al control de entrega existente y refresca su resumen tras guardar. La modalidad combinada añade nueve etapas para nuevos seguimientos; no convierte historiales ya publicados. La navegación interna separa seguimiento, revisión/entrega y materiales; los formularios conservan sus IDs. No requiere migración adicional, pero 0008 y 0009 siguen pendientes de autorización. El registro de entrega combinado sigue siendo único, no admite entregas parciales independientes.
